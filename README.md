## 📌 About the Project
**NariSuraksha** is an emergency, victim-centric crisis response and legal empowerment web portal engineered specifically for women in India facing Non-Consensual Intimate Imagery (NCII) leaks, AI-generated deepfakes, cyber blackmail, and online harassment.

### Core Features
- ⚡ **Emergency Crisis Flowchart & Action Checklists**: Step-by-step guidance for blackmailers, WhatsApp/Telegram leaks, and Instagram impersonation.
- 🛑 **Direct Platform Takedown Gateway**: Quick links & protocol instructions for StopNCII.org, Meta, WhatsApp Grievance Officer, Telegram, and X.
- 📋 **Cyber Crime Complaint Generator**: Auto-formats formal legal complaints tailored to the **Indian Information Technology Act, 2000** and **Bharatiya Nyaya Sanhita, 2023**.
- 🦺 **One-Touch Disguise / Quick Exit (Camouflage Mode)**: Instantly switches the screen to a discreet "Polity Revision Notes" study interface with escape key triggers.
- 📱 **100% Client-Side Privacy**: Operates fully within the user's browser with no server-side tracking of sensitive victim inputs.

## 🚀 Quickstart & Local Replication

To clone and run this application locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/Manishpoonam/narisuraksha.git

# 2. Navigate into the project folder
cd narisuraksha

# 3. Install dependencies
npm install

# 4. Start the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your web browser.

## 🌐 Deploying to GitHub Pages (Zero Blank-Page Trap)

This repository is already pre-configured to build without the common **"blank white screen"** issue on GitHub Pages:

1. **Relative Asset Paths**: `vite.config.ts` specifies `base: './'` so all JavaScript, CSS, and asset bundles load relative to whatever subpath repository you host on.
2. **Jekyll Bypass**: A `.nojekyll` file exists in `public/` so GitHub doesn't drop bundled assets.
3. **Automated GitHub Action**: `.github/workflows/deploy.yml` builds and deploys the application automatically upon pushing to `main`.

### Deployment Steps:
1. Fork or push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, choose **GitHub Actions**.
4. Push a commit or trigger the workflow under the **Actions** tab. Your website will be live in under 60 seconds!
