# Security Policy

## Reporting Security Vulnerabilities

The security and privacy of individuals using NariSuraksha is of paramount importance.

If you believe you have found a security vulnerability or privacy concern in this repository, please disclose it directly and responsibly:

- **Maintainer & Lead Developer:** Manish Poonam Kashyap
- **Email:** manishkumarkashyap14@gmail.com
- **Response SLA:** Within 24 hours

Please do **not** file public issues on GitHub for undisclosed security vulnerabilities. All verified reports will be patched promptly.
